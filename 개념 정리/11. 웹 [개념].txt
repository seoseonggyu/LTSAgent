웹 프론트엔드의 3요소
- 모든 웹 페이지는 이 세가지로 구성된다.
- HTML(뼈대): "무엇이 있는지"
- CSS(옷): "어떻게 보이는지"
- JavaScript(근육): "어떻게 움직이는지"

문제: 백엔드는 C#인데 프론트는 JavaScript?
- 새로운 언어를 처음부터 배워야 함
- 코드 공유 불가 -> 모델 클래스를 양쪽에 각각 정의
- 기술 스택이 분리 -> 복잡성 증가

Blazor 탄생
- Microsoft가 하나의 언어로 전체 웹 앱을 개발할 수 있게
- C#으로 프론트를 만들 게 해줌

Blazor
- Microsoft가 만든 C# 웹 프론트엔드 프레임워크
- 핵심: JavaScript 대신 C#으로 프론트엔드 로직을 작성
- 백엔드도 C#, 프론트도 C# -> 하나의 언어로 전체 웹 앱
- .razor 파일에서 HTML과 C#을 함께 사용

JavaScript를 완전히 없애는 건 아니다
- 브라우저 고유 기능은 여전히 JS 필요
- 스크롤 제어 (채팅창 자동 스크롤), 클립보드 접근 (복사/붙여넣기), DOM 직접 조작

정리
- 웹 = 백엔드(주방) + 프론트엔드(홀) + API(주문서)
- 모든 웹 = HTML + CSS + JS
- Blazor = C#으로 프론트엔드를 만드는 프레임워크
- JS를 줄이되 완전히 없애지는 않음
- C# Agent + Blazor + SignalR = 우리 프로젝트에 딱 맞는 선택
