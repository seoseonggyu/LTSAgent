web_fetch
- web_search를 통해 나온 검색 결과 목록에 대한 링크를 클릭해서 실제 글을 읽는 것. 페이지 안의 내용을 직접 확인하고 정보를 가져옴.

web_fetch가 하는 일: 입력과 출력
- Input: url(읽고 싶은 웹 페이지 주소), prompt(이 페이지에서 뭘 알고 싶은지)
- output: 요약된 결과 텍스트(페이지에서 프롬프트에 맞는 핵심 정보만 추출하여 반환)

HTML -> Markdown 변환
- HTML을 그대로 AI에게 주면 불필요한 코드가 너무 많아 토큰 낭비
- Markdown으로 변환하면 사람이 읽는 것처럼 본문만 깔끔하게 전달
- 텍스트가 아닌 컨텐츠 (이미지, 바이너리, PDF 등)는 거부

신뢰 도메인 구분
- 모든 웹 페이지를 동일하게 처리하지 않는다. 출처에 따라 전력이 달라진다.
- 신뢰 도메인 + 짧은 내용 -> 원문 그대로
- 신뢰 도메인 + 긴 내용 -> AI 요약
- 비신뢰 도메인  -> AI 요약 + 저작권 보호

캐시 - 같은 페이지를 또 안 읽기
- 캐시 없이 (Before): 같은 URL 3번 요청하면 매번 네트워크 요청을 3회. 느리고, 서버에 부담을 주고, 같은 결과를 또 가져옴
- 캐시 있으면 (After): 처음 1번만 네트워크 요청. 이후 같은 URL은 캐시에서 즉시 반환.
- 캐시 유효 시간(TTL, 15분), 최대 캐시 크기(LRU, 50MB)
- 15분이 지나면 캐시 만료 -> 다시 가져옴.
- 전체 크기가 50MB를 넘으면 가장 오래된 것부터 삭제 (LRU 정책).
