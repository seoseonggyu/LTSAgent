Agent에서 모드는 2가지 존재. Agent에게 바로 행위를 수행하기 위한 Edit 모드, 체계적인 계획을 통해 진행할 수 있는 PlanMode 모드가 존재

왜 모드가 두 개일까?
- 간단한 작업을 바로 실행하는 게 빠르다
- 복잡하거나 위험한 작업은 먼저 계획을 확인하고 싶다
- 사용자가 상황에 따라 선택할 수 있어야 한다
- 핵심 -> 모든 작업에 같은 방식을 적용하는 것은 비효율적이다. 간단한 일에 복잡한 절차를 거치면 느리고, 복잡한 일을 무작정 시작하면 위험하다

비유로 이해하기
- 현장 작업자(EditMode) -> "나무 배치해줘" -> 바로 배치
- 설계사(PlanMode) -> "나무 배치해줘" -> 계획대로 배치

EditMode 바로 실행 모드
- 사용자가 요청하면 Agent가 즉시 판단하고 실행
- Tool 호출, 코드 생성 등을 바로 수행
- 중간 확인 단계 없이 결과 직행
- 빠르고 간단하지만 이탈 가능성 존재
- 단순 질문, 작은 수정, 빠른 반복, 즉시 실행 같은 경우에 적합

PlanMode 계획 먼저, 실행은 나중에
- Agent가 먼저 계획을 세워서 보여주고, 승인 후 실행
- 실행 전에 무엇을 할지 명확히 공유
- 사용자가 계획을 수정하거나 거부 가능
- 방향 확인, 실수 방지, 한 단계 추가
- 복잡한 작업, 위험한 작업, 여러 단계, 되돌리기 어려운 작업에 적합
