LLM
- 두뇌: 방대한 텍스트를 학습한 AI의 "두뇌". 스스로 생각하고 추론하는 능력을 가짐. 문제는 외부와 상호작용은 불가

Agent
- 로봇: 두뇌가 없음. 두뇌가 없으니 스스로 판단이 불가. 그래서 LLM 두뇌를 장착해 스스로 판단 및 행위를 할 수 있게 해주는 게 Agent

Tool
- 도구: 로봇의 팔이라고 생각. LLM과 Agent가 합쳐서 Agent가 실제로 일을 할 때 사용하는 다양한 도구들. 망치, 드릴, 측정기처럼 각각 특정 작업을 수행. Tool 없이는 로봇도 할 수 있는 일이 제한된다. ex) 웹 검색, 파일 관리, 계산, API 호출

MCP
- 표준 소켓: 도구는 도구다. 로봇 팔을 만드는 회사가 많을 경우, 회사마다 로봇 팔 장착 방식이 다르기 때문에 함부로 장착이 불가하다. 그래서 로봇팔을 만들 때, 모두 동일한  방식으로 만들어서 로봇이 어디 회사를 가도 원할하게 장착할 수 있는 표준이다.

Tool
- Function Calling: LLM이 "이 상황에서는 이 도구를 써야겠다"고 판단하고, 도구를 호출하는 메커니즘
- ex) 사용자 질문 -> LLM 판단 -> Tool 호출 요청 -> Tool 실행 -> 결과 반환
- 요약: Tool은 Agent가 외부 세계와 상호작용하기 위해 사용하는 "도구"이며, Function Calling을 통해 LLM이 적절한 도구를 선택하고 호출한다.

MCP (Model Context Protocol)
- 비유: MCP는 "표준 소켓(콘센트)". 예전에는 각 나라마다 콘센트 모양이 달라서 어댑터가 필요했지만, MCP는 모든 도구를 같은 방식으로 연결할 수 있게 해주는 통일 규격
