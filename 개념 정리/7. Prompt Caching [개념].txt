Prompt Caching
- 토큰을 아껴주는 동시에 AI 답변이 빠르게 오도록 해주는 매커니즘이다.
- 매번 다시 읽지 말고, 기억을 시키는 것이다.
- 반복되는 콘텐츠를 Anthropic 서버에 일시적으로 캐시
- 다음 요청 시 캐시된 부분은 다시 처리하지 않고 재사용 -> 비용 절감 + 응답 속도 향샹

CacheControlEphemeral 이란?
- Ephemeral = 일시적인
- 캐시가 영구적이지 않음
- 약 5분 후 자동 만료
- 사용 중에는 계속 재활용
- CacheControl = new CacheControlEphemeral(); 한 줄만 추가

적용 위치
- 시스템 프롬프트 (매 요청마다 동일하므로 캐시 효과 극대화) -> 가장 대표적
- 긴 문서 / 컨텍스트 (큰 PDF 내용을 넣어두고 여러 질문을 할 때)
- 대화 히스토리의 앞부분 (이미 지나간 대화를 캐시하여 재처리 방지)
- 중요 규칙: 캐시는 앞에서부터 연속된 부분만 가능. 중간만 캐시할 수 없다.
