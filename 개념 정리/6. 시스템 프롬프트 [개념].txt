시스템 프롬프트
- LLM에게 주는 기본 설정서
- API 요청 시 system 필드에 넣는 텍스트
- 사용자에게는 보이지는 않지만 LLM의 모든 응답에 영향을 줌
- user/assistant 메시지와 달리 대화 전체를 관통하는 기본 지침
- 매 API 호출마다 동일하게 전송되어 일관된 동작을 보장
- 같은 Claude 모델 하나로 완전히 다른 서비스를 만들 수 있다.

주의
- 컨텍스트 윈도우를 차지한다
- 시스템 프롬프트가 길수록 대화에 쓸 수 있는 공간이 줄어듬
- 핵심만 간결하게 하고 불필요한 내용은 과감히 삭제
- API 요청 시에 영어로 쓰는 게 굉장히 유리하다. 기본적으로 컨텍스트를 줄이기 위한 노력도 있지만 영어 데이터가 더 많아서다.
