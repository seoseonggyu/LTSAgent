claude.ai vs API
- 같은 Claude, 다른 사용법
- claude.ai: 식당에 직접 가서 먹기. 홈페이지에 들어가서 채팅창에서 대화. 사용자에 대한 검증 필요가 없음. 단점은 커스텀이 불가능
- API: 배달앱으로 주문하기. 내 프로그램이 Calude 호출. 사용자에 대한 검증 필요. 그게 바로 API Key. 장점은 커스텀이 가능

API Key란?
- 호텔 카드키와 같다. Key가 있어야 내 방(Claude)에 들어갈 수 있다.
- Key가 필요한 이유는 AI 호출 비용이 비싸기 때문이다. 호출할 때 마다 매번 서버 비용이 발생해서 Key를 통해 누가 쓰는지, 얼마나 쓰는지, 문제 시 즉시 차단하기 위해 필요하다.
- 4가지의 역할: 인증, 과금, 추척, 차단 -> Key는 신용카드와 연결된 디지털 신분증으로 생각
- 중요한 점은 Key 번호는 처음 발급받을 때만 볼 수 있다. 그래서 반드시 복제해야함

정리
- API Key = Claude를 프로그램으로 쓰기 위한 디지털 열쇠
- Console에서 만들고 관리한다
- 절대 남에게 보여주면 안 된다
